    What is txtshell?

    A fast, local-first text editor. Everything stays on your device — no accounts, no cloud, no tracking. Just type and save.

    How it works

    Type anything in the editor. Press ⌘/Ctrl + ⏎ to save it as a block. That's the core loop — write, save, find later.

    Finding your blocks

    ⌘/Ctrl + K opens search. Type to filter, use #tags and @mentions to organise. Or type a word followed by // in the editor and press ⏎ to search it.

    Useful commands

    /re reopens your latest block for editing

    /t shows today's blocks, /y yesterday's

    /w shows last week

    /pin shows pinned blocks

    /q opens the full shortcut reference

    Optional features

    /encrypt encrypts your blocks locally with a passphrase

    /export downloads an encrypted backup of your blocks

    /export plain downloads an unencrypted plaintext backup

    /import restores from an export file

    The pitch

    — the first-visit screen on why your notes are unreadable to anyone but you.

    Quick Retrieval

    term // + ⏎ -> open search with that term

    #tag // + ⏎ -> open search filtered to that tag

    @name // + ⏎ -> open search filtered to that mention

    Shift + ⏎ after term // -> edit the first matching block

    /- -> pick from your tags; /-tag opens most recently edited block tagged #tag

    Commands

    /re -> reopen your most recent saved block in the editor

    /t -> show blocks saved today

    /ta -> show blocks created or edited today

    /otd -> on this day: blocks from today's date in earlier months and years

    /y -> show blocks saved yesterday

    /ya -> show blocks created or edited yesterday

    /w -> show blocks saved during the last week

    /wa -> show blocks created or edited in the last 7 days

    /pin -> show only pinned blocks

    ☆/★ on a block -> toggle pin

    /import -> import blocks from an export file

    /500 -> set a word/char/line count target (Esc to clear)

    /font 12 -> set note font size for the editor and saved blocks (11–24px); /font reset restores the 14px default

    /sym -> chemistry & math symbol palette: click to insert ₂ → Δ ²⁺ as plain text; H_2O → H₂O, Ca^2+ → Ca²⁺, ∫_0^1 → ∫₀¹, ∫_a^b → ∫ₐᵇ, ∑_{n=1}^{2n}, e^{-x} → e⁻ˣ via its convert button (∞ and π have no small glyph and stay as typed). Type ;; (after a space or at a line start) or press ⌘/Ctrl + . to toggle it mid-note

    /q -> open this help sheet

    Encryption

    /encrypt -> encrypt your blocks with a passphrase

    /encrypt change -> change your passphrase

    /encrypt off -> remove encryption and restore plaintext

    /lock -> lock the vault (clears decrypted data from memory)

    Save your recovery key when shown -> it is the only way back if you forget your passphrase

    Editor

    ⌘/Ctrl + ⏎ -> save the current block

    ⌘/Ctrl + Shift + ⏎ -> reopen your most recent block

    ⌘/Ctrl + Shift + F -> open find and replace

    Esc -> cancel editing and clear the editor

    Tab / Shift + Tab -> indent / outdent

    Search

    ⌘/Ctrl + K -> open search

    ⌘/Ctrl + Shift + H -> open this reference sheet

    Several words -> only blocks containing all of them; mix in #tag or @name to narrow further

    ↑/↓ -> move through results

    Enter -> expand or collapse the selected result

    Links in blocks are clickable -> they open in a new tab

    ⌘/Ctrl + ⌫ -> delete the selected block

    ⌘/Ctrl + C -> copy the selected block (or the whole multi-selection)

    Shift + ⏎ -> edit the selected block

    Shift + click or Shift + ↑/↓ -> select multiple (for copy, merge or delete)

    Esc -> clear the multi-selection, then close search

    Toolbar

    ⌨ button -> cycle counter: words / chars / lines / off

    ↓ button -> export blocks (encrypted, requires unlocked vault)

    ↑/↓ -> move Enter -> expand Shift + ⏎ -> edit Shift + click -> select multiple Esc -> back
